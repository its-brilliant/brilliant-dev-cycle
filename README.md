# brilliant-dev-cycle (bdc) v2

You type what you want built. bdc grills you on it, writes a spec you review, plans phases, runs builders in parallel worktrees, reviews and verifies every phase with proof, and opens a pull request you can trust. It asks you only when a person must decide.

Status: being rebuilt from the agreed spec. Nothing runs yet.
